# Security Policy

This is a small multiplayer web game — the socket layer accepts real-time input from
untrusted clients, so reports of anything that lets one player affect another player's
session outside the rules (state corruption, crashes, injection) are welcome.

## Reporting a Vulnerability

Please **do not** open a public issue for security reports. Instead:

- Use [GitHub Security Advisories](https://github.com/sidharth18jam/the-system/security/advisories/new) to report privately, or
- Open an issue asking to be contacted, without details, and we'll follow up privately.

We'll acknowledge reports within a few days and aim to patch confirmed issues before
any public disclosure.
